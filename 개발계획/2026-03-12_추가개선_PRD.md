## E-1: 테이블 일괄 선택 및 일괄 처리 (Bulk Select)

### 배경

사유서 관리, 수강생 목록 등에서 여러 항목을 처리할 때 한 건씩 클릭해야 함.

| 페이지 | 일괄 작업 |

| 수강생 목록 | 일괄 비활성화, 일괄 기수 변경 |
| 알림 발송 | 선택된 수강생에게만 발송 |
| 성적 목록 | 선택 행 일괄 삭제 |

### 구현

**신규 컴포넌트: `web/src/components/ui/bulk-select-table.tsx`**

## E-2: 필터 프리셋 저장 (Filter Presets)

### 배경

관리자가 매일 "공채 + 이번 달 + PENDING 상태" 같은 동일한 필터 조합을 반복 입력.
자주 쓰는 필터 조합을 저장하고 1클릭으로 불러오는 기능.

### 구현 방법

**localStorage 기반 (DB 저장 불필요)**:

```typescript
// web/src/hooks/use-filter-presets.ts
import { useState } from 'react'

interface FilterPreset {
  id: string
  name: string
  filters: Record<string, string>
  createdAt: string
}

export function useFilterPresets(storageKey: string) {
  const [presets, setPresets] = useState<FilterPreset[]>(() => {
    try {
      return JSON.parse(localStorage.getItem(storageKey) ?? '[]')
    } catch { return [] }
  })

  const savePreset = (name: string, filters: Record<string, string>) => {
    const newPreset: FilterPreset = {
      id: Date.now().toString(),
      name,
      filters,
      createdAt: new Date().toISOString(),
    }
    const updated = [...presets, newPreset]
    setPresets(updated)
    localStorage.setItem(storageKey, JSON.stringify(updated))
  }

  const deletePreset = (id: string) => {
    const updated = presets.filter(p => p.id !== id)
    setPresets(updated)
    localStorage.setItem(storageKey, JSON.stringify(updated))
  }

  return { presets, savePreset, deletePreset }
}
```

**UI**: 필터 폼 우측에 "현재 필터 저장" 버튼 + 저장된 프리셋 드롭다운

```typescript

<div className="flex items-center gap-2">

```

## E-4: 공지사항 Rich Text 에디터

### 배경

현재 공지사항 내용이 plain text. 볼드, 링크, 리스트, 강조 등 서식 불가.
중요 공지(탈락 기준 변경, 특별 시험 안내 등)에 구조화된 내용이 필요.

### 구현 방법

**패키지**: `@tiptap/react` (Notion-style 에디터, 가장 가볍고 Next.js 호환)

```bash
npm install @tiptap/react @tiptap/pm @tiptap/starter-kit
```

**신규 컴포넌트: `web/src/components/ui/rich-text-editor.tsx`**

```typescript
import { useEditor, EditorContent } from '@tiptap/react'
import StarterKit from '@tiptap/starter-kit'

export function RichTextEditor({
  content,
  onChange,
}: {
  content: string
  onChange: (html: string) => void
}) {
  const editor = useEditor({
    extensions: [StarterKit],
    content,
    onUpdate: ({ editor }) => onChange(editor.getHTML()),
  })

  return (
    <div className="border border-ink/10 bg-white">
      {/* 툴바 */}
      <div className="flex gap-1 border-b border-ink/10 p-2">
        <button onClick={() => editor?.chain().focus().toggleBold().run()}
          className={editor?.isActive('bold') ? 'bg-ink text-white px-2 py-1 text-xs' : 'px-2 py-1 text-xs border'}>
          B
        </button>
        <button onClick={() => editor?.chain().focus().toggleBulletList().run()}
          className="px-2 py-1 text-xs border">
          • 목록
        </button>
        <button onClick={() => editor?.chain().focus().toggleHeading({ level: 2 }).run()}
          className="px-2 py-1 text-xs border">
          제목
        </button>
      </div>
      {/* 에디터 영역 */}
      <EditorContent
        editor={editor}
        className="min-h-[200px] p-4 text-sm [&_.ProseMirror]:outline-none"
      />
    </div>
  )
}

// 읽기 전용 뷰어
export function RichTextViewer({ html }: { html: string }) {
  return (
    <div
      className="prose prose-sm max-w-none text-ink [&_strong]:font-bold [&_ul]:list-disc [&_ul]:pl-4"
      dangerouslySetInnerHTML={{ __html: html }}
    />
  )
}
```

**DB 변경**: `notices.content` 는 이미 `String` 타입이므로 HTML 저장 가능 (변경 불필요)

### 수용 기준

- [ ] 공지사항 작성 시 볼드, 리스트, 제목 서식 적용 가능
- [ ] 저장된 HTML이 공지 목록/상세에서 올바르게 렌더링
- [ ] XSS 방지: 허용된 태그만 렌더링 (DOMPurify 또는 tiptap 자체 sanitize)

## E-7: 기수별 코호트 분석 (Generation Cohort Analysis)

### 배경

"1기 vs 2기 vs 3기 탈락률이 어떻게 다른가?" 같은 운영 인사이트가 필요.
각 기수의 성적 추이, 탈락률, 개근률을 비교하면 커리큘럼 개선에 활용 가능.

### 구현 방법

**신규 탭 or 페이지: `/admin/analytics` 에 "기수 비교" 탭 추가**

```typescript
// 기수별 통계 집계 쿼리 (예시)
const cohortStats = await prisma.$queryRaw`
  SELECT
    s.generation,
    COUNT(DISTINCT s."examNumber") as totalStudents,
    COUNT(DISTINCT CASE WHEN s."currentStatus" = 'DROPOUT' THEN s."examNumber" END) as dropoutCount,
    AVG(CAST(sc."finalScore" AS FLOAT)) as avgScore,
    COUNT(DISTINCT CASE WHEN sc."attendType" = 'NORMAL' THEN sc.id END)::FLOAT /
      NULLIF(COUNT(DISTINCT sc.id), 0) * 100 as attendanceRate
  FROM students s
  LEFT JOIN scores sc ON sc."examNumber" = s."examNumber"
  LEFT JOIN exam_sessions es ON es.id = sc."sessionId"
  WHERE es."periodId" = ${periodId}
  GROUP BY s.generation
  ORDER BY s.generation
`

// 시각화:
// - 기수별 탈락률 바 차트
// - 기수별 평균 점수 추이
// - 기수별 개근률 비교
// - 히트맵: 기수 × 과목 평균 점수
```

### 수용 기준

- [ ] 기수별 탈락률, 평균 점수, 출석률 비교 차트 표시
- [ ] 기간 선택 가능
- [ ] 공채/경채 구분 필터

## V-1: KPI 카드 스파크라인 (Sparklines)

```typescript
// 또는 더 가벼운 SVG 직접 구현 (추천)

// web/src/components/ui/sparkline.tsx
function Sparkline({ data, color = '#C55A11' }: { data: number[]; color?: string }) {
  if (data.length < 2) return null
  const max = Math.max(...data)
  const min = Math.min(...data)
  const range = max - min || 1
  const width = 80
  const height = 24

  const points = data.map((v, i) => {
    const x = (i / (data.length - 1)) * width
    const y = height - ((v - min) / range) * height
    return `${x},${y}`
  }).join(' ')

  const trend = data[data.length - 1] - data[0]

  return (
    <div className="flex items-center gap-1">
      <svg width={width} height={height} className="overflow-visible">
        <polyline
          points={points}
          fill="none"
          stroke={color}
          strokeWidth="1.5"
          strokeLinecap="round"
          strokeLinejoin="round"
        />
      </svg>
      <span className={`text-xs font-semibold ${trend >= 0 ? 'text-forest' : 'text-red-600'}`}>
        {trend >= 0 ? '▲' : '▼'}{Math.abs(trend).toFixed(1)}
      </span>
    </div>
  )
}
```

```typescript
export function DeltaBadge({ current, previous }: { current: number; previous?: number }) {
  if (previous === undefined || previous === null) return null
  const diff = current - previous
  if (Math.abs(diff) < 0.1) return <span className="text-xs text-slate">—</span>

  return (
    <span className={`inline-flex items-center gap-0.5 text-xs font-semibold ${
      diff > 0 ? 'text-forest' : 'text-red-600'
    }`}>
      {diff > 0 ? '▲' : '▼'}{Math.abs(diff).toFixed(1)}
    </span>
  )
}
```

```typescript
// sm 미만에서는 카드 형태, sm 이상에서는 테이블 형태
export function ResponsiveTable<T>({
  data,
  columns,
  keyField,
}: {
  data: T[]
  columns: {
    key: keyof T
    label: string
    render?: (value: T[keyof T], row: T) => React.ReactNode
  }[]
  keyField: keyof T
}) {
  return (
    <>
      {/* 테이블 (sm+) */}
      <div className="hidden sm:block overflow-x-auto">
        <table>
          <thead>
            <tr>
              {columns.map(col => <th key={String(col.key)}>{col.label}</th>)}
            </tr>
          </thead>
          <tbody>
            {data.map(row => (
              <tr key={String(row[keyField])}>
                {columns.map(col => (
                  <td key={String(col.key)}>
                    {col.render ? col.render(row[col.key], row) : String(row[col.key] ?? '')}
                  </td>
                ))}
              </tr>
            ))}
          </tbody>
        </table>
      </div>

      {/* 카드뷰 (모바일) */}
      <div className="sm:hidden space-y-3 p-4">
        {data.map(row => (
          <div key={String(row[keyField])} className="border border-ink/10 bg-white p-4 space-y-2">
            {columns.map(col => (
              <div key={String(col.key)} className="flex justify-between text-sm">
                <span className="text-slate text-xs">{col.label}</span>
                <span className="text-ink font-medium">
                  {col.render ? col.render(row[col.key], row) : String(row[col.key] ?? '')}
                </span>
              </div>
            ))}
          </div>
```

```typescript
        <button onClick={reset} className="bg-ink px-5 py-2 text-sm font-semibold text-white hover:bg-forest transition">
          다시 시도
        </button>
        <a href="/admin" className="border border-ink/10 px-5 py-2 text-sm font-semibold hover:text-ember transition">
          대시보드로
        </a>
      </div>
    </div>
  )
}
```

## X-7: 키보드 단축키 레퍼런스 (Shortcut Reference)

### 배경

UI-10(Cmd+K)을 포함해 키보드 단축키를 추가하면 사용자가 어떤 단축키가 있는지 알아야 함.
`?` 키를 누르면 단축키 목록 모달이 뜨는 패턴 (VS Code, GitHub 표준).

### 구현 방법

```typescript
// ? 키 누르면 모달 표시
useEffect(() => {
  const down = (e: KeyboardEvent) => {
    if (e.key === '?' && !e.ctrlKey && !e.metaKey) {
      // input/textarea에서는 무시
      if (document.activeElement?.tagName === 'INPUT') return
      if (document.activeElement?.tagName === 'TEXTAREA') return
      e.preventDefault()
      setShortcutOpen(v => !v)
    }
  }
  document.addEventListener('keydown', down)
  return () => document.removeEventListener('keydown', down)
}, [])

// 단축키 목록
const SHORTCUTS = [
  { key: 'Ctrl + K', desc: '빠른 페이지 이동' },
  { key: '?', desc: '단축키 목록 보기' },
  { key: 'Esc', desc: '모달/팔레트 닫기' },
  { key: 'Ctrl + Enter', desc: '폼 제출' },
]
```
