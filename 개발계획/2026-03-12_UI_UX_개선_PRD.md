## 1. UI-1: 토스트 알림 시스템 (Toast Notifications)

### 1.1 배경

현재 성공/실패 메시지가 폼 내부 인라인 텍스트로만 표시됨.
사용자가 스크롤 위에 있으면 메시지를 보지 못하고 지나칠 수 있음.
모든 현대 SaaS(Linear, Notion, Vercel 등)에서 표준 패턴.

### 1.2 요구사항

| ID | 내용 | 우선순위 |
|----|------|---------|
| UI-1-F1 | 성공 토스트: 초록(forest), 우측 상단, 3초 후 자동 닫힘 | 높음 |
| UI-1-F2 | 오류 토스트: 빨강, 우측 상단, 5초 또는 수동 닫기 | 높음 |
| UI-1-F3 | 경고 토스트: ember, 4초 | 중간 |
| UI-1-F4 | 정보 토스트: 파랑, 3초 | 낮음 |
| UI-1-F5 | 여러 토스트 동시 표시 시 스택 형태로 쌓임 | 중간 |
| UI-1-F6 | 토스트 위에 마우스 올리면 자동 닫힘 타이머 일시 정지 | 낮음 |

### 1.3 구현 방법

**패키지**: `sonner` (Next.js App Router 공식 권장, bundle size 작음)

```bash
npm install sonner
```

**설정**: `web/src/app/admin/layout.tsx` 에 추가

```typescript

  toastOptions={{
    classNames: {

      error:   'border-red-300 bg-red-50 text-red-700',
      warning: 'border-ember/30 bg-ember/10 text-ember',
    },
    duration: 3000,

```

**사용 패턴 (기존 인라인 메시지 교체)**:

```typescript

// 성공
toast.success('사유서가 승인되었습니다.')

// 실패
toast.error('저장 중 오류가 발생했습니다.')

try {

  toast.success('성적이 저장되었습니다.', { id: toastId })
} catch {
  toast.error('저장 실패. 다시 시도해주세요.', { id: toastId })
}
```

## 2. UI-2: 스켈레톤 로딩 UI (Skeleton Loading)

### 2.1 배경

현재 데이터 로딩 중 빈 화면 또는 버튼 비활성화만 표시됨.
사용자가 "앱이 멈췄나?" 라고 오해하는 원인이 됨.
스켈레톤 UI는 실제 로딩 속도보다 체감 속도를 30~40% 빠르게 느끼게 함.

### 2.2 요구사항

| ID | 내용 | 우선순위 |
|----|------|---------|
| UI-2-F1 | 대시보드 KPI 카드 로딩 시 스켈레톤 표시 | 높음 |
| UI-2-F2 | 테이블 데이터 로딩 시 5~10행 스켈레톤 표시 | 높음 |
| UI-2-F3 | 차트 로딩 시 사각형 스켈레톤 표시 | 중간 |
| UI-2-F4 | 스켈레톤은 shimmer(반짝이는) 애니메이션 적용 | 중간 |

### 2.3 구현 방법

**별도 패키지 불필요** — TailwindCSS로 직접 구현.

**신규 파일: `web/src/components/ui/skeleton.tsx`**

```typescript
// web/src/components/ui/skeleton.tsx
import { cn } from '@/lib/utils'  // 기존 유틸 사용

export function Skeleton({ className }: { className?: string }) {
  return (
    <div
      className={cn(
        'animate-pulse bg-ink/8',
        className
      )}
    />
  )
}

// 카드 스켈레톤
export function CardSkeleton() {
  return (
    <div className="border border-ink/10 bg-white p-5">
      <Skeleton className="h-3 w-24 mb-3" />
      <Skeleton className="h-9 w-16 mb-2" />
      <Skeleton className="h-3 w-32" />
    </div>
  )
}

// 테이블 행 스켈레톤
export function TableRowSkeleton({ cols = 5 }: { cols?: number }) {
  return (
    <tr>
      {Array.from({ length: cols }).map((_, i) => (
        <td key={i} className="px-4 py-3">
          <Skeleton className="h-4 w-full max-w-[120px]" />
        </td>
      ))}
    </tr>
  )
}

// 테이블 스켈레톤 (n행)
export function TableSkeleton({ rows = 8, cols = 5 }: { rows?: number; cols?: number }) {
  return (
    <>
      {Array.from({ length: rows }).map((_, i) => (
        <TableRowSkeleton key={i} cols={cols} />
      ))}
    </>
  )
}

// 차트 스켈레톤
export function ChartSkeleton({ height = 280 }: { height?: number }) {
  return <Skeleton className="w-full" style={{ height }} />
}
```

**`globals.css`에 shimmer 애니메이션 추가**:

```css
/* 기존 @keyframes 아래에 추가 */
@keyframes shimmer {
  0%   { background-position: -200% 0; }
  100% { background-position: 200% 0; }
}

.animate-shimmer {
  background: linear-gradient(
    90deg,
    #f0f0f0 25%,
    #e0e0e0 50%,
    #f0f0f0 75%
  );
  background-size: 200% 100%;
  animation: shimmer 1.5s infinite;
}
```

**사용 예시 — 대시보드**:

```typescript
// web/src/app/admin/page.tsx

// Suspense 또는 isLoading 조건부 렌더링
{isLoading ? (

  </div>
) : (
  // 실제 KPI 카드
)}
```

## 3. UI-3: 모바일 사이드바 (Hamburger Menu)

### 3.1 배경

현재 `lg(1024px)` 미만에서 사이드바가 완전히 숨겨짐.
모바일/태블릿 환경에서 페이지 간 이동 수단이 없음.
관리자가 iPad나 모바일로 접근하는 경우 완전히 불편.

### 3.2 요구사항

| ID | 내용 | 우선순위 |
|----|------|---------|
| UI-3-F1 | 모바일 상단에 햄버거(≡) 버튼 표시 | 높음 |
| UI-3-F2 | 햄버거 클릭 시 사이드바 오버레이로 슬라이드 인 | 높음 |
| UI-3-F3 | 오버레이 배경 클릭 시 닫힘 | 높음 |
| UI-3-F4 | 페이지 이동 후 자동으로 닫힘 | 높음 |
| UI-3-F5 | 데스크톱(lg+)에서는 기존 사이드바 유지 | 높음 |

### 3.3 구현 방법

**수정 파일: `web/src/app/admin/layout.tsx`**

```typescript
'use client'
import { useState, useEffect } from 'react'
import { usePathname } from 'next/navigation'

export default function AdminLayout({ children }) {
  const [mobileOpen, setMobileOpen] = useState(false)
  const pathname = usePathname()

  // 페이지 이동 시 자동 닫힘
  useEffect(() => { setMobileOpen(false) }, [pathname])

  return (
    <div className="flex min-h-screen">

      {/* 모바일 오버레이 배경 */}
      {mobileOpen && (
        <div
          className="fixed inset-0 z-40 bg-ink/50 lg:hidden"
          onClick={() => setMobileOpen(false)}
        />
      )}

      {/* 사이드바 — 모바일: 슬라이드 / 데스크톱: 고정 */}
      <aside
        className={[
          'fixed z-50 h-full w-[260px] bg-sidebar transition-transform duration-300 lg:static lg:translate-x-0',
          mobileOpen ? 'translate-x-0' : '-translate-x-full',
        ].join(' ')}
      >
        {/* 기존 사이드바 내용 유지 */}
        <AdminSidebarContent />
      </aside>

      {/* 메인 */}
      <div className="flex flex-1 flex-col">

        {/* 모바일 상단 앱바 */}
        <header className="flex items-center border-b border-ink/10 bg-white px-4 py-3 lg:hidden">
          <button
            onClick={() => setMobileOpen(true)}
            className="p-2 text-ink hover:text-ember"
            aria-label="메뉴 열기"
          >
            {/* 햄버거 아이콘 (SVG) */}
            <svg width="20" height="20" viewBox="0 0 20 20" fill="currentColor">
              <rect y="3" width="20" height="2" />
              <rect y="9" width="20" height="2" />
              <rect y="15" width="20" height="2" />
            </svg>
          </button>
          <span className="ml-3 text-sm font-semibold text-ink">아침모의고사 관리</span>
        </header>

        <main className="flex-1">{children}</main>
      </div>
    </div>
  )
}
```

### 3.4 수용 기준

- [ ] 768px 화면에서 햄버거 버튼 표시
- [ ] 햄버거 클릭 시 300ms 슬라이드 애니메이션으로 사이드바 등장
- [ ] 오버레이 또는 다른 페이지 이동 시 닫힘
- [ ] 1024px 이상에서는 기존 고정 사이드바 유지

## 4. UI-4: 현재 페이지 활성 표시 (Active Navigation)

### 4.1 배경

현재 사이드바에서 어떤 페이지에 있는지 강조 표시가 없음.
사용자가 현재 위치를 파악하기 어렵고 UX의 기본 요소가 빠져 있음.

### 4.2 구현 방법

**수정 파일: `web/src/app/admin/layout.tsx`** (또는 AdminSidebarContent)

```typescript
'use client'
import { usePathname } from 'next/navigation'

// 각 네비게이션 링크에 적용
const pathname = usePathname()

// 링크 클래스 조건부 적용
const isActive = pathname === item.href || pathname.startsWith(item.href + '/')

<Link
  href={item.href}
  className={[
    'flex items-center gap-2 px-3 py-2 text-sm transition',
    isActive
      ? 'border-l-2 border-ember bg-white/10 text-white font-semibold'
      : 'border-l-2 border-transparent text-gray-300 hover:bg-white/5 hover:text-white',
  ].join(' ')}
>
  {item.label}
</Link>
```

### 4.3 수용 기준

- [ ] 현재 URL과 일치하는 네비게이션 항목에 ember 좌측 보더 + 배경 표시
- [ ] 하위 경로(`/admin/students/123`)에서도 상위 항목(`/admin/students`) 활성 표시
- [ ] 페이지 이동 시 즉시 업데이트

## 5. UI-5: 사이드바 접기/펼치기 (Collapsible Sidebar)

### 5.1 배경

화면이 작은 노트북(1280px 미만)에서 사이드바 260px가 콘텐츠 영역을 압박함.
SaaS 어드민 표준 패턴: 아이콘만 보이는 접힌 상태(64px) 지원.

### 5.2 요구사항

| ID | 내용 | 우선순위 |
|----|------|---------|
| UI-5-F1 | 사이드바 하단 또는 헤더에 접기 토글 버튼 | 중간 |
| UI-5-F2 | 접힌 상태: 64px 너비, 아이콘만 표시 | 중간 |
| UI-5-F3 | 펼친 상태: 260px, 아이콘 + 텍스트 | 중간 |
| UI-5-F4 | 상태를 localStorage에 저장 (새로고침 유지) | 중간 |
| UI-5-F5 | 접힌 상태에서 호버 시 툴팁으로 메뉴명 표시 | 낮음 |

### 5.3 구현 방법

**전제**: 먼저 아이콘 라이브러리 도입 (UI-6 참조)

```typescript
// 상태 저장
const [collapsed, setCollapsed] = useState(() => {
  if (typeof window === 'undefined') return false
  return localStorage.getItem('sidebar-collapsed') === 'true'
})

const toggle = () => {
  setCollapsed(v => {
    localStorage.setItem('sidebar-collapsed', String(!v))
    return !v
  })
}

// 사이드바 너비
<aside className={`transition-all duration-300 ${collapsed ? 'w-16' : 'w-[260px]'}`}>
  {/* 네비게이션 링크: 접힌 상태에서는 아이콘만 */}
  <Link href={item.href} title={collapsed ? item.label : undefined}>
    <Icon className="shrink-0" />
    {!collapsed && <span>{item.label}</span>}
  </Link>
</aside>
```

### 5.4 수용 기준

- [ ] 토글 버튼 클릭 시 300ms 애니메이션으로 접기/펼치기
- [ ] 접힌 상태에서 아이콘만 표시
- [ ] localStorage에 상태 저장, 새로고침 후 유지
- [ ] 접힌 상태에서 아이콘 호버 시 툴팁으로 메뉴명 표시

## 6. UI-6: 아이콘 라이브러리 도입 (Lucide React)

### 6.1 배경

현재 전체적으로 텍스트 기반 UI. 아이콘이 거의 없음.
아이콘은 정보 전달 속도를 높이고, 시각적 스캐닝을 쉽게 함.
Lucide-React는 Next.js 공식 예제에서 사용, tree-shaking 지원.

### 6.2 구현 방법

```bash
npm install lucide-react
```

**적용 위치 우선순위**:

```typescript
import {
  LayoutDashboard, Users, FileText, Bell, BarChart2,
  MessageSquare, Award, LogOut, Menu, X, ChevronLeft,
  ChevronRight, Search, Settings, Download, Upload,
  CheckCircle, XCircle, AlertTriangle, Info, RefreshCw,
```

## 7. UI-7: 브레드크럼 (Breadcrumbs)

### 7.1 배경

현재 깊은 페이지(`/admin/students/2026001`)에서 현재 위치를 파악하기 어려움.
특히 `[examNumber]` 동적 경로는 학생 이름 없이 수험번호만 표시됨.

### 7.2 구현 방법

**신규 파일: `web/src/components/ui/breadcrumbs.tsx`**

```typescript
'use client'
import Link from 'next/link'
import { usePathname } from 'next/navigation'
import { ChevronRight } from 'lucide-react'

const ROUTE_LABELS: Record<string, string> = {
  admin:          '관리자',
  students:       '수강생 관리',
  scores:         '성적',
  input:          '입력',
  edit:           '수정',
  analytics:      '성적 분석',
  periods:        '시험 기간',
  notifications:  '알림 발송',
  'absence-notes':'사유서 관리',
  counseling:     '면담',
  points:         '포인트',
  dropout:        '탈락·경고',
  export:         '내보내기',
  'audit-log':    '감사 로그',
  notices:        '공지사항',
  settings:       '설정',
  results:        '성적표',
  integrated:     '전체 성적표',
  monthly:        '월별 성적표',
  query:          '다차원 조회',
}

export function Breadcrumbs({ dynamicLabels }: { dynamicLabels?: Record<string, string> }) {
  const pathname = usePathname()
  const segments = pathname.split('/').filter(Boolean)  // ['admin', 'students', '2026001']

  const crumbs = segments.map((seg, i) => {
    const href = '/' + segments.slice(0, i + 1).join('/')
    const label = dynamicLabels?.[seg] ?? ROUTE_LABELS[seg] ?? seg
    const isLast = i === segments.length - 1
    return { href, label, isLast }
  })

  if (crumbs.length <= 1) return null

  return (
    <nav className="flex items-center gap-1 text-xs text-slate mb-4">
      {crumbs.map((crumb, i) => (
        <span key={crumb.href} className="flex items-center gap-1">
          {i > 0 && <ChevronRight className="h-3 w-3 text-slate/40" />}
          {crumb.isLast ? (
            <span className="text-ink font-medium">{crumb.label}</span>
          ) : (
            <Link href={crumb.href} className="hover:text-ink transition">
              {crumb.label}
            </Link>
          )}
        </span>
      ))}
    </nav>
  )
}
```

**사용 예시 (학생 상세 페이지)**:


## 8. UI-8: 테이블 열 정렬 (Column Sorting)

### 8.1 배경

모든 테이블(학생 목록, 성적 목록, 사유서 목록 등)에서 열 정렬 기능 없음.
이름순, 점수순, 날짜순으로 보고 싶을 때 매번 필터를 다시 설정해야 함.

### 8.2 구현 방법

**신규 컴포넌트: `web/src/components/ui/sortable-th.tsx`**

```typescript
'use client'
import { ChevronUp, ChevronDown, ChevronsUpDown } from 'lucide-react'

type SortDirection = 'asc' | 'desc' | null

interface Props {
  label: string
  sortKey: string
  currentSortKey?: string
  currentDirection?: SortDirection
  onSort: (key: string, dir: SortDirection) => void
}

export function SortableTh({ label, sortKey, currentSortKey, currentDirection, onSort }: Props) {
  const isActive = currentSortKey === sortKey

  const handleClick = () => {
    if (!isActive) onSort(sortKey, 'asc')
    else if (currentDirection === 'asc') onSort(sortKey, 'desc')
    else onSort(sortKey, null)  // 정렬 해제
  }

  return (
    <th
      onClick={handleClick}
      className="cursor-pointer select-none px-4 py-3 text-left text-xs font-bold uppercase tracking-wider hover:bg-ink/5 transition"
    >
      <span className="flex items-center gap-1">
        {label}
        {isActive && currentDirection === 'asc' && <ChevronUp className="h-3 w-3 text-ember" />}
        {isActive && currentDirection === 'desc' && <ChevronDown className="h-3 w-3 text-ember" />}
        {!isActive && <ChevronsUpDown className="h-3 w-3 text-slate/40" />}
      </span>
    </th>
  )
}
```

**적용 방식**: URL 파라미터 기반 (서버 컴포넌트 친화적)

```typescript

  orderBy: { [sortKey]: sortDir },
```

**사용 예시 — 수강생 등록 폼**:

```typescript
import { useForm } from 'react-hook-form'
import { zodResolver } from '@hookform/resolvers/zod'
import { z } from 'zod'

const schema = z.object({
  examNumber: z.string()
    .min(1, '수험번호를 입력해주세요.')
    .regex(/^\d{7}$/, '수험번호는 7자리 숫자여야 합니다.'),
  name: z.string().min(2, '이름은 2자 이상이어야 합니다.').max(10, '이름은 10자 이하여야 합니다.'),
  phone: z.string().regex(/^010-\d{4}-\d{4}$/, '전화번호 형식: 010-0000-0000'),
})

type FormData = z.infer<typeof schema>

export function StudentForm() {
  const { register, handleSubmit, formState: { errors } } = useForm<FormData>({
    resolver: zodResolver(schema),
  })

  return (
    <form onSubmit={handleSubmit(onSubmit)}>
      <div>
        <input {...register('examNumber')} placeholder="수험번호 (7자리)" />
        {errors.examNumber && (
          <p className="mt-1 text-xs text-red-600">{errors.examNumber.message}</p>
        )}
      </div>
    </form>
  )
}
```

```typescript
}
```

## 18. 공통 주의사항

1. **`border-radius: 0 !important`**: 전역 CSS가 모든 radius를 직각으로 강제함 — 추가하는 모든 컴포넌트 자동 적용되므로 별도 처리 불필요
2. **색상**: 커스텀 색상(ember/forest/ink/mist/slate)만 사용, Tailwind 기본 색상(gray-700 등)은 점진적으로 교체
3. **폰트**: Pretendard Variable이 적용되어 있음 — 아이콘 SVG는 `currentColor` 사용 권장
4. **서버/클라이언트 분리**: UI 인터랙션 컴포넌트는 `'use client'` 마킹, 데이터 페칭은 서버 컴포넌트 유지
5. **테이블 스타일**: `globals.css`의 `table` 전역 스타일이 강제 적용됨 — 새 컴포넌트에서 Tailwind 인라인 스타일과 충돌 확인 필요
6. **애니메이션**: `transition-all duration-300` 패턴 일관되게 사용
