## 2. 상단 탭 (Top Navigation)

### 2-1. 탭 구성

| 탭 | 아이콘 | 접근 권한 | URL 기준 |
|---|---|---|---|
| 대시보드 | 🏠 | 전체 | `/admin` |
| 수강관리 | 👥 | ACADEMIC 이상 | `/admin/members/*` |
| 수납·결제 | 💳 | CASHIER 이상 | `/admin/payments/*` |
| 성적관리 | 📊 | VIEWER 이상 | `/admin/scores/*`, `/admin/analytics/*` |
| 출결관리 | 📋 | VIEWER 이상 | `/admin/attendance/*` |
| 시설관리 | 🏢 | ACADEMIC 이상 | `/admin/facilities/*` |
| 시스템 | ⚙️ | DIRECTOR 전용 | `/admin/staff/*`, `/admin/settings/*` |

### 2-2. 탭 UI 상세

```
┌──────────────────────────────────────────────────────────────────────┐
│                                                                      │
│  ◈ AcadPro   대시보드  수강관리  수납·결제  성적관리  출결  시설  ⚙  │
│              ─────────                                               │
│              현재탭 밑줄                              [🔔2] [홍원장 ▾]│
└──────────────────────────────────────────────────────────────────────┘

스타일:
- 배경: ink(#111827) 다크 바
- 일반 탭: 흰색 60% 투명도 텍스트
- 선택된 탭: 흰색 100% + 하단 ember(#C55A11) 2px 밑줄
- 호버: 흰색 80%
- 높이: 56px
- 탭 간격: px-5
```

### 2-3. 알림 아이콘

```
🔔 숫자 뱃지 = 처리 필요 항목
  - 미승인 사유서
  - 미납 독촉 예정
  - 면담 예약

클릭 시: 드롭다운으로 항목 목록 표시
```

## 4. 학생 상세 페이지 (특수 레이아웃)

학생 개별 페이지(`/admin/members/[id]`)는 **탭 UI**를 사용한다.
좌측 사이드바 없이 콘텐츠 내 탭으로 전환.

```
┌──────────────────────────────────────────────────────────────────────┐
│  TOP NAV: [수강관리 탭 선택됨]                                       │
├──────────┬───────────────────────────────────────────────────────────┤
│  수강    │  ← 수강생 목록                                           │
│  관리    │  홍길동 (2024001)  공채·52기·A반  [재원]                  │
│  사이드  │                                                           │
│  바      │  [수강내역] [수납이력] [성적분석] [출결] [면담] [문서]    │
│          │  ─────────                                               │
│  (기존   │                                                           │
│  메뉴    │  수강 내역 탭 콘텐츠...                                   │
│  유지)   │                                                           │
└──────────┴───────────────────────────────────────────────────────────┘
```

## 5. 모바일 반응형 처리

### 태블릿 (768px~1024px)
- 사이드바: 아이콘만 표시 (220px → 60px 축소)
- 호버 시 툴팁으로 메뉴명 표시

### 모바일 (768px 미만)
- 상단 탭: 스크롤 가능한 가로 탭
- 사이드바: 숨김 → 햄버거 버튼으로 드로어 열기

> Next.js 14 App Router의 **Route Groups** `(폴더명)` 기능을 사용한다.
> `(members)` 같은 괄호 폴더는 URL에 영향을 주지 않으면서 레이아웃을 분리할 수 있다.
> 즉 `/admin/(members)/members` → 실제 URL은 `/admin/members`

## 7. 기존 페이지 마이그레이션 전략

기존 `/admin/*` 페이지들은 URL 변경 없이 Route Group으로 재분류만 하면 된다.

```
현재: web/src/app/admin/analytics/page.tsx
이동: web/src/app/admin/(scores)/analytics/page.tsx
URL:  /admin/analytics (동일 — 변경 없음)
```

**마이그레이션 순서**:
1. `admin/layout.tsx` 신규 생성 (TOP NAV 추가)
2. `(scores)` 그룹 먼저 생성 → 기존 성적 관련 페이지 이동
3. 나머지 그룹 순차 생성
4. 기존 성적 관련 Nav 컴포넌트 제거

## 9. 장점 정리

| 항목 | 기존 방식 (하나의 긴 사이드바) | 신규 방식 (상단탭 + 모듈 사이드바) |
|---|---|---|
| 메뉴 수 | 30개+ 한 화면에 | 7개 탭, 탭당 4~8개 |
| 인지 부하 | 높음 (모든 메뉴 노출) | 낮음 (현재 모듈만 표시) |
| 역할별 관리 | 전체 목록 필터링 | 탭 자체를 숨김 처리 |
| 확장성 | 메뉴 추가 시 길어짐 | 탭에 새 모듈 추가 |
| 컨텍스트 유지 | 페이지 이동 시 위치 파악 어려움 | 탭으로 현재 위치 명확 |
