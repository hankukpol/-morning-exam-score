### 🆕 A. 현금영수증 발행

#### A-1. 기능 개요

현금 또는 계좌이체로 수납 시 국세청 현금영수증 발행.
학생(소득공제용) 또는 사업자(지출증빙용) 선택 가능.

#### A-2. 발행 흐름

```
현금/계좌이체 수납 등록
    ↓
현금영수증 발행 여부 선택
  [발행 안함]  [소득공제용]  [지출증빙용]
    ↓ 발행 선택 시
휴대폰 번호 또는 사업자번호 입력
    ↓
국세청 홈택스 API 전송 (자동)
    ↓
승인번호 수령 → 수납 기록에 저장
    ↓
영수증 화면에 현금영수증 승인번호 표시
```

#### A-3. 수납 등록 화면 추가 항목

```
수납 등록
  결제 수단: [ ● 현금  ○ 카드  ○ 계좌이체  ○ 포인트 ]
  금액: [ 600,000 ] 원
  ─────────────────────────────────────────────
  현금영수증 발행
  [ ○ 발행 안함  ● 소득공제용  ○ 지출증빙용 ]
  휴대폰 번호: [ 010-1234-5678 ]  (자동 입력 — 학생 연락처)
  ─────────────────────────────────────────────
  [저장 및 발행]
```

#### A-4. 현금영수증 발행 이력

```
/admin/payments/cash-receipts

발행 이력
  발행일        학생명    금액        승인번호      유형
  2026-03-13   홍길동    600,000원   12345678     소득공제
  2026-03-12   김철수    150,000원   12345677     소득공제
  ...
  [국세청 조회] [재발행 요청]
```

#### A-5. 연말 교육비 납입 확인서

연말정산 시즌에 학생이 요청하는 문서:

```
/admin/members/[id]/documents → [교육비 납입 확인서] 출력

교육비 납입 확인서
  성명: 홍길동  주민번호: ******-*******
  2026년 납입 교육비 합계: 1,350,000원
  (현금영수증 발행분 + 카드 결제분 합산)
  위와 같이 확인합니다. ○○공무원학원
```

#### A-6. 국세청 API 연동

- API: 국세청 현금영수증 발행 API (홈택스)
  - 연동 방식: 현금영수증 자진발급 번호 등록 또는 API 직접 연동
  - 대안: 초기에는 **수동 발행** (직원이 단말기로 발행 후 승인번호 수기 입력)
  - 자동화: Phase 2에서 API 연동

```
설정: /admin/settings/cash-receipt
  발행 방식: [ ○ 수동 입력  ● API 자동 ]
  사업자번호: [ 000-00-00000 ]
  가맹점 코드: [ xxxxxxxxx ]
```

### 🆕 B. 카드 단말기 VAN 연동

#### B-1. 기능 개요

카운터에 설치된 카드 단말기(POS 단말기)와 시스템을 연동하여, 카드 결제 시 자동으로 수납 내역이 기록되고 영수증이 출력된다.

**지원 VAN사**: KICC, KIS정보통신, NICE페이먼츠, 한국정보통신(KSNET), 나이스정보통신

#### B-2. 연동 방식

```
방식 1: TCP/IP 소켓 직접 연동 (권장)
  카드 단말기 ←→ PC(포트 8080) ←→ 웹앱 API
  - 결제 요청: 웹앱 → PC 에이전트 → 단말기
  - 결제 결과: 단말기 → PC 에이전트 → 웹앱

방식 2: 수동 매칭 (초기 운영)
  카드 단말기로 결제 완료 후 웹앱에서 수납 처리
  - 직원이 단말기 영수증의 승인번호를 수납 화면에 직접 입력
  - API 연동 전 임시 운영 방식
```

#### B-3. 카드 결제 흐름 (자동 연동)

```
수납 등록 화면
  결제 수단: [ ○ 현금  ● 카드  ○ 계좌이체  ○ 포인트 ]
  금액: [ 600,000 ] 원
  [카드 결제 요청]
      ↓
단말기에서 카드 삽입/태그
      ↓
VAN사 서버 승인
      ↓
결과 수신 (승인번호, 카드사, 할부개월)
      ↓
수납 DB 자동 저장 + 영수증 출력
```

#### B-4. 카드 결제 UI

```
카드 결제 진행 중...
  ┌──────────────────────────────────┐
  │  단말기에서 카드를 삽입해 주세요  │
  │                                  │
  │         💳 카드 삽입/태그         │
  │                                  │
  │  금액: 600,000원                  │
  │  [취소]                           │
  └──────────────────────────────────┘

결제 완료
  ┌──────────────────────────────────┐
  │  ✅ 결제 승인 완료               │
  │  승인번호: 12345678              │
  │  카드: 신한카드 **** 1234         │
  │  할부: 일시불                     │
  │  금액: 600,000원                  │
  │  [영수증 출력] [확인]             │
  └──────────────────────────────────┘
```

#### B-5. 카드 결제 취소 (환불 연동)

```
환불 처리 시 카드 결제 취소:
  원거래 승인번호 확인 → 카드사 취소 전문 전송 → 취소 완료
  취소 가능 기간: 카드사 정책에 따름 (통상 당일 또는 동월)
  기간 초과 시: 현금 환불로 전환 처리
```


#### B-7. 신규 DB 모델 (카드 결제)

```prisma
model CardPayment {
  id              String   @id @default(cuid())

  cardNoMasked    String                  // 카드번호 마스킹 (**** 1234)

  cancelApprovalNo String?

  @@map("card_payments")
}

enum VanType { KICC KIS NICE KSNET KCP }
```

### 🆕 D. 수강 신청 폼 (온라인 접수)

#### D-1. 기능 개요

학원 홈페이지에 삽입할 수 있는 온라인 수강 신청 폼.
신청자 정보가 시스템으로 자동 접수되어 상담 대기 상태로 등록.

```
공개 URL: /apply  (학원 홈페이지에 링크 또는 iframe)

수강 신청서
  이름: [            ]
  연락처: [          ]
  희망 강좌: [ 공채 종합반 ▼ ]
  수강 경험: [ ○ 처음  ○ 재수강 ]
  문의 내용: [                  ]
  개인정보 수집 동의: [ ☑ 동의합니다 ]
  [신청하기]
```

→ 신청 시 `ConsultationRecord` 자동 생성 (stage: PENDING)
→ 담당 직원에게 SMS 알림: "새 수강 신청이 접수되었습니다."

## 5. 신규 DB 모델

```prisma
model CashReceipt {
  id            String   @id @default(cuid())
  paymentId     String   @unique        // Payment.id 연결
  examNumber    String
  amount        Int                     // 발행 금액
  receiptType   CashReceiptType         // INCOME_DEDUCTION / BUSINESS_EXPENSE
  identityNo    String                  // 휴대폰번호 또는 사업자번호
  approvalNo    String?                 // 국세청 승인번호
  issuedAt      DateTime @default(now())
  issuedBy      String                  // 처리 직원
  method        CashReceiptMethod       // AUTO_API / MANUAL

  payment       Payment  @relation(...)
  student       Student  @relation(...)

  @@map("cash_receipts")
}

model CashReceiptSettings {
  id            Int      @id @default(1)
  method        CashReceiptMethod  @default(MANUAL)
  businessNo    String?            // 사업자번호
  merchantCode  String?            // 홈택스 가맹점 코드
  apiKey        String?
  updatedAt     DateTime @updatedAt
  @@map("cash_receipt_settings")
}

enum CashReceiptType   { INCOME_DEDUCTION BUSINESS_EXPENSE }
enum CashReceiptMethod { AUTO_API MANUAL }
```
